# PJSK中虚拟歌手和原创角色的关系研究

PJSK OC–Virtual Singer 关系评测：v2.3 定向审计复跑

完成日期：2026-09-19。本文沿用用户的CPU/SoC隐喻：CPU0是初始化与基础结构地位，S/P/E表示叙事重要性和强度；不解释成CP、好感度或同框频率。

**结论：原版的大方向有多项能成立，但120个具体分数没有被验证；宁宁的关键S级依据存在明确的因果顺序错误，彰人的主线贡献分配也需要重写。冬弥、奏、司、类应重新开放竞争。真冬—Miku的CPU0判断可以与排名分开保留。**

本轮建立118条OC–VS记账项（117条正分、1条零分对照），引用108话，涉及46个活动及4条组合主线。多条账目可能来自同一场景，因此118不表示118个互不相关的剧情事件。核查方式为关键章通读与相关对白、前后因果段落核查相结合。

这是针对给定基线和竞争证据的抽样复跑，不是截至2026年的全剧情普查。计分活动最晚到2024年的活动150；卡牌与区域对话未系统覆盖。下面的Raw是**已核查事件在指定编码下的Raw**，不是角色全部剧情的真实总量。等级、主动性和影响倍率仍是分析判断，不能因为数学可复算就叫客观测量。

完整逐项账本见 [PJSK_ledger.md](PJSK_ledger.md)，机器账本见 [PJSK_event_ledger.json](PJSK_event_ledger.json)，计算结果见 [PJSK_scores.json](PJSK_scores.json)。

**最关键的因果核查**

1. **宁宁—MEIKO：撤销所给事件的创伤S。** 第6话中宁宁观看自己的童年录像，重新理解享受表演，并恢复练习；第7话MEIKO才初次出场，确认宁宁已经恢复。MEIKO随后提供开场合唱的机会，这是实质支持，但不是造成此前心理转折的原因。本轮记B：16×1.10×1.35的假设性重事件，改为3×1.10×1.00=3.30。这个修正只针对该事件，不宣称MEIKO在其他剧情中不可能承担S级功能。来源：[聖なる夜に、この歌声を·第6话「魔法をかけて」](https://pjsk.moe/ja-jp/story/event/8/6/)、[聖なる夜に、この歌声を·第7话「セカイの新団員！？」](https://pjsk.moe/ja-jp/story/event/8/7/)。

2. **彰人—Len/MEIKO：不能把共同场景的关键转折全给Len。** Len用搭档经验接住彰人的失落；MEIKO借酒杯里的乌龙茶指出表象不必是真相，彰人才想到冬弥的话可能不是本心并立即行动。本轮分别记Len B与MEIKO A。同场出现不是同等因果贡献。来源：[Vivid BAD SQUADストーリー 第1章·第17话「レンとMEIKOととっておき」](https://pjsk.moe/ja-jp/story/unit/4/street_01_17/)。

3. **咲希—Len：原表5分漏掉了重节点。** Len建议继续挖掘歌曲尚未表达出来的住院感受，咲希接受并寻找答案；后续作曲完成。这里给A，保留她自己面对过去及朋友支持的作用。再加实际键盘辅导，本轮Len Raw为13.86，对比Rin 15.84，无法把他解释成几乎纯日常核。来源：[No seek No find·第5话「感情の不協和音」](https://pjsk.moe/ja-jp/story/event/65/5/)、[No seek No find·第7话「この想い、出しきるまで」](https://pjsk.moe/ja-jp/story/event/65/7/)、[Don't lose faith!·第4话「不安を蹴散らして」](https://pjsk.moe/ja-jp/story/event/69/4/)。

4. **冬弥—KAITO：不只有搭档建议。** KAITO指出冬弥理解作品心意的能力来自古典分析训练，Miku将其表述为了解歌曲心意的力量，冬弥随后在实践中回想。这补上了自我认同线程；本轮KAITO Raw 34.32，Luka 26.76。不过该事件从S降A就会让Luka反超，故是可争论的竞争判断。来源：[Walk on and on·第6话「伝わるといいな」](https://pjsk.moe/ja-jp/story/event/71/6/)、[Walk on and on·第7话「込められた願い」](https://pjsk.moe/ja-jp/story/event/71/7/)。

5. **司与类：Miku不能被结构身份遮蔽。** 司的主线由Miku点明让哭泣者微笑的意义，KAITO共同重连其明星初心；类后来也向Miku主动倾诉，Miku确认追梦与和伙伴演出两种心意都重要。前者本轮并列，后者的领先对分级敏感；都不足以直接宣判全局Miku必胜。来源：[ワンダーランズ×ショウタイムストーリー 第1章·第14话「あの日の想い」](https://pjsk.moe/ja-jp/story/unit/5/wonder_01_14/)、[カーテンコールに惜別を·第6话「どちらも大事な」](https://pjsk.moe/ja-jp/story/event/74/6/)。

6. **奏—KAITO：有本人主线，不能只算旁听真冬事件。** KAITO指出奏在否定自身愿望，与绘名共同鼓励她面对自己的幸福。第8话奏确实写出承载个人幸福愿望的曲子。Rin先前的音乐初心回顾也有独立作用；所以这是一条多人参与、但可区分行为的因果链。来源：[あの日、奏でた音色を·第4话「辿る、記憶の先は」](https://pjsk.moe/ja-jp/story/event/116/4/)、[あの日、奏でた音色を·第7话「願い」](https://pjsk.moe/ja-jp/story/event/116/7/)、[あの日、奏でた音色を·第8话「あの日の音色を」](https://pjsk.moe/ja-jp/story/event/116/8/)。

7. **瑞希—MEIKO：成立的强证据来自实际介入与复现。** 早期仅向其他VS说明关注与距离，不能自动计成改变瑞希的S。WL中她明确推动瑞希面对自己；活动150又实际介入退缩危机。与此同时，Luka帮助瑞希把逃避经验转为支持真冬的能力，也是需要计入的核心贡献。来源：[シークレット・ディスタンス·第5话「最後の心霊スポット」](https://pjsk.moe/ja-jp/story/event/19/5/)、[水底に影を探して·第4话「逃げた、その先は」](https://pjsk.moe/ja-jp/story/event/112/4/)、[水底に影を探して·第5话「やさしい言葉」](https://pjsk.moe/ja-jp/story/event/112/5/)、[傷だらけの手で、私達は·第7话「逃走」](https://pjsk.moe/ja-jp/story/event/150/7/)、[傷だらけの手で、私達は·第8话「友達」](https://pjsk.moe/ja-jp/story/event/150/8/)、[ボク達の生存逃走·第6话「ボクの方法」](https://pjsk.moe/ja-jp/story/event/93/6/)。

8. **杏与笑梦：共同作用要拆开说明。** 杏的Len是意外触发者，Miku进一步追问；能证明两人都关键，却不能仅凭这段推出100∶92。笑梦的Len与Rin共同帮助她承认难过，Rin不能消失于摘要。镜像、气质相近都不单独产生85分。来源：[Bout for Beside You·第5话「路地裏の会話」](https://pjsk.moe/ja-jp/story/event/37/5/)、[Bout for Beside You·第6话「モヤモヤしていた理由」](https://pjsk.moe/ja-jp/story/event/37/6/)、[スマイルオブドリーマー·第6话「涙のような笑顔より」](https://pjsk.moe/ja-jp/story/event/15/6/)。

**评分约定与必须修正的模型问题**

- 本轮保留S=16、A=8、B=3、C=1及原A/I候选值。U统一设1.00作为中性审计设定：覆盖不足时不授独占奖励。它不是关于所有关系均等独特的事实判断，也未套用泛用互动0.80折扣。未来可修改JSON逐项U再重算。

- 同一连续谈话跨章合并；后来回想同一段建议只作为影响证据，不再新建重事件。相同OC–VS–主题按等级、衰减前Raw排序，再用1、0.6、0.35、0.2。零分对照不占重复序号。

- 同一行动不能通过换标签加分；另行完成的教学、分享作品等行动可单列。主题边界仍会影响结果，因此提供把同一OC–VS所有主题合并衰减的压力测试。该测试比原规则更严，不是默认替换。

- 不要求参与一场戏的VS共同分掉一个固定分池；各自要有独立的可说明贡献，U=1记录共享功能。OC、伙伴及NPC的贡献另在摘要中保留，不能被VS吞掉。

- 第4次以后恒定20%仍然可以无限累积：再加n个同权事件仍增加0.2nE。它只能减缓刷分，不能数学上防止无限刷分。建议下一版明确采用尾部几何衰减或每主题上限；本轮为可比性没有暗改。

- 2.2次幂不改变同一OC内部的名次，却显著改变断崖与Core Type。Raw相对第一为80%时，显示分只有61.2；显示70对应Raw约85.0%。因此Core阈值属于模型选择，不是剧情事实。

- 原表真冬100∶95隐含第二名Raw约为第一名97.7%，仅差约2.3%。这不影响CPU0结构判断，却与“几乎无合理竞争者”的排名A+标准紧张。原表20个D的算术均正确；错误风险主要在事件、分级、覆盖与倍率，而非减法。

- 原Core定义没有完整处理第二项55—70、≥90以及E-core的边界。此次显示为过渡形或高竞争双峰，不自行补成确定等级。S事件、S-core、CPU0是三个不同对象。

原handoff多次称为“官方回顾”的[2022-10-23 Famitsu文章](https://www.famitsu.com/news/202210/23261737.html)是媒体回顾。即使概括有参考价值，也不能替代正文，或凭2022年的回顾证明后续全时期排序。本轮未用该文章单独给分。
