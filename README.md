# PJSK 虚拟歌手与原创角色的关系研究

截至2026-10-12日服公开剧情，研究20名原创角色与6位虚拟歌手的120组关系。成长作用与情感表现分开评分，每组列9个维度的理由、独立剧情线及日文来源。

**114组完成本轮正文证据窗口核验；一歌6组沿用既有首评。** 补查原5项情感待查后，成长和情感120组原始指数均完整；新增各角色两套最高值分别为100的相对分，原始档位与指数保留。这是有来源的首轮研究编码，不是4147篇全文逐行穷尽审计或官方结论。

## 分数是什么

成长方向是VS对OC，向量[K,C,S,T,B]，按K→S→C→T→B优先比较；显示指数只用于阅读。情感方向是OC对VS，分别看表达、信任/袒露、主动投入、关系定位。两种分数不相加，不作为恋爱、人气或真实内心百分比。相对分按同角色同指标六位VS最高原始值归一到100，不同角色的100不能直接比较绝对深度。宁宁、类的成长因果优先序与指数最高者不同，图表分别列出。每项解释与限制均在全角色报告。

当前待查已补足，未来新缺口仍不记0。含待查维度时情感原指数为空；组内基准不完整时该套相对分整体留空，雷达保留缺口。可能范围仅为缺失项取0–4的数学边界，不是统计置信区间。相同分档不意味着情节相同，2/3档、时期与功能分类仍可修订。任何同分都必须深入评价：46个初始组合已完成比较，遥—连与杏—铃的主动投入据正文从2改3；重算后的新/变化组合也已复查。无法可靠区分者保留并列并注明理由，校验器拒绝未经深评的新同分。

## 本轮主要发现

不同角色的关系倾向有明显区别。不能把六人都有互动称为六人同等重要，也不能把共同感谢平均变成每个人的独立强线。

一歌—Miku的原始根基地位保留；扩大全角色后，心羽—铃/连有由杏演唱作品承接的道路起点，真冬—Miku有与奏共同被本人赋予的根基意义。K4并非全20人只允许Miku或某一个角色获得，现实作品作用也不等同SEKAI面对面教育。

魔法未来部分年份其他五人的参与曲数相等，但Miku仍明显多于各人。**观察到分配结果均衡，不足以证明PJSK造成变化，或确认某家公司/某人指使削弱Miku。** 补查到CP官方说明2021周年3DMV上映会关注组合平衡，但这是特定活动编排，不是六VS剧情/魔法未来统一均分方针。公开职责与边界详见端水研究，均附官方来源。
