# PJSK 虚拟歌手与原创角色的关系研究

在《Project SEKAI》中，初音未来、镜音铃、镜音连、巡音流歌、MEIKO 和 KAITO，分别怎样参与了20名原创角色的成长？

有人帮助角色作出重要决定，有人陪伴角色重新认识自己，也有人影响了角色最初走上音乐道路的原因。本项目从具体剧情出发，整理这些作用，并比较它们为什么重要。

**V3 成长评分只描述虚拟歌手对原创角色成长的结构性重要程度，不量化感情。** 本项目另设“情感四维试评分”，记录原创角色在正文中对虚拟歌手表现出的情感表达、信任、主动投入与关系定位。两项分别展示，不合成总分，也不解释为恋爱、配对、人气或“谁最爱谁”的排名。一个角色可以同时受到多位虚拟歌手的重要影响，也可以珍惜多段关系。

## 目前做到哪一步了？

当前采用 **V3 评价方法**，从影响深度、独立成长经历、角色自己的说法、持续时间和帮助范围五个方面分析关系。

仓库原有的历史数字来自 **2026年9月19日完成的 v2.3 抽样核查**：共118条关系记录，引用108话，涉及46个活动和4条组合主线。多条记录可能来自同一个场景，所以不等于118个独立事件。

这批资料尚未按 V3 逐对重新评价，**目前没有已经完成核验的 V3 全角色评分表**。旧资料最晚覆盖到2024年的活动150，卡牌剧情和区域对话也没有系统查全。旧版分数放在文末折叠区，不能作为截至2026年的完整排名。

## 为什么把这些问题放在一起？

一歌的首轮分析提出了一个值得追问的问题：Miku拥有突出的人物根基与关系定位，其他五位VS却也与一歌建立了具体、持续的关系。这是否说明官方在照顾六人，甚至在“端水”？这种安排是否影响Miku的特殊性？演唱会上感受到的个人舞台减少，又是否属于同一种变化？

本文把这些问题放在一起研究，但不把剧情分数和演唱会曲数合成总分。两类材料观察的是不同对象，不能相互充当因果证据。

**当前最有证据的判断：Miku在一歌关系中仍有特殊地位；魔法未来部分年份的独唱份额下降，其他五人的参与曲数出现完全相等的配置。后者支持“分配结果均衡”，尚不能证明“强行端水”、CFM有意削弱Miku，或变化由PJSK造成。**

## 材料怎样使用？

|材料|本文用途|不能单独证明什么|
|---|---|---|
|游戏日文剧情及本仓库证据记录|评价角色关系；本轮仍是候选检索后重点精读|全库无遗漏、编剧内部动机|
|官方演后曲目表|计数歌手署名、曲目次序、替换配置|实际演唱分钟、镜头、站位或每人的声部份额|
|官网及官方公开说明|说明对外定位和项目参与主体|内部预算、配额、未公开的选曲指令|
|社区帖子与个人观演文章|展示不同期待与解释|总体民意、官方态度、剧情因果|
|本文的解释与猜想|提出可证伪的研究方向|既成事实|

成长V3及原A+～F置信度体系保持不变。社区意见不进入角色分数；下文“已观察／待验证”也不替代原有置信度等级。

## 一歌：差距看起来不大，究竟说明什么？

|VS|成长指数|情感指数|当前关系判断|
|---|---:|---:|---|
|初音未来|100.00|100.00|唯一K4；情感四项均到本次尺度上限|
|巡音流歌|77.67|68.75|重要师友、信任与主动关心|
|KAITO|77.67|68.75|创作支持、持续感谢与信任|
|MEIKO|74.67|56.25|成长支持较突出，不能直接换成情感深度|
|镜音铃|68.42|68.75|加入回礼、关心、陪伴与袒露后，相对位置上升|
|镜音连|68.42|56.25|已有具体关系，尚未支持与Miku同级的特殊定位|

以上沿用[一歌报告](../ichika/README.md)，没有因本专题重新调分。成长按K→S→C→T→B排序；情感指数方向为一歌→VS。Miku两项置信度暂为A，其他暂为B；不是全剧情逐段人工审计的最终排名。

**77.67分不是“Miku重要性的77.67%”，68.75分也不是“感情有她的近七成”。** 当前分数是分档换算，不能解释为真实关系强度的比例。

模型本身会压缩视觉差距：K4与K3在显示指数里只差12.5分，但在排序中先区分因果层级；C在四条强剧情线后封顶；历史上建立的持续关系不会因近期戏份少就自动扣分。情感的3档允许由跨情境持续表现支持，也使不同性质的师友关系容易聚集在中高档。

因此，当前结果更直接挑战“其他VS只是陪衬”的看法，并未推翻“Miku具有特殊地位”。不能为了得到预期中的巨大领先，恢复2.2次幂等人为拉大差距的做法。

“一歌是20名OC中与Miku关系最深的角色”仍是待同口径比较的预期。其余114组关系未完成V3评价，不能从一歌推断其他角色一定更平衡；另一位VS显著领先，也不等于六人接近。

## “端水”需要拆成哪些可检验的问题？

本文保留“端水”作为讨论中的说法，具体区分如下：

|问题|需要观察什么|目前能说到哪里|
|六人都获得有意义的内容？|各自是否有具体作用与关系发展|一歌首轮证据支持其他VS不是纯背景|
|份额是否均衡？|同口径曲数、场景数、关键行动的分布|魔法未来有五人参与曲数完全相等的年份|
|功能是否同质化？|是否反复由不同VS执行相同建议、安慰和解决路径|尚无全库比较，不能认定|
|是否牺牲人物逻辑？|是否淡化既有关系定位，或让缺乏铺垫的人承担关键转折|需要具体前后文，不能由同分直接推出|
|是否削弱Miku？|绝对内容减少、相对份额下降、特殊定位淡化应分别检查|曲数层面有局部下降；身份或关系被否定未证明|
|是否有统一政策？|制作访谈、公开方针、可归属的决策证据|本次检索未找到足以证明统一削弱方针的材料|

其他人增加不必然意味着Miku减少；但历史高分也不能排除近期重要内容减少。后续应按时间段另记Miku的新关键行动、主动关系发展，以及角色在有多个对象可求助时选择了谁。**特殊性不自动进入V3奖励，也不因其他人重要而自动扣分。**

## 魔法未来2020—2026：曲目中的出场比例

### 统计范围与口径

这里的“出场比例”严格指**官方曲目表歌手署名的曲目参与率**，并非录像实测在场时间。只署名Miku记为独唱；署名含Miku与他人记为参与合唱。每首在总曲数中计一次。多个歌手参与同一首时，各人的参与曲数各加一，因此六人的参与曲数不能横向加总当作演出总数。

### “存在感下降”得到多大支持？

**已观察：独唱份额有明显低谷，不能描述为逐年下降。** 2023与2025较低，2024与2026回升。2020到2026，Miku独唱由11首增到13首，占比却由61.1%降到50%；含合唱参与率从66.7%到65.4%，很接近。绝对量、相对份额必须分开。

**已观察：2024→2025，个人曲目与共同参与发生变化。** 总曲数24→25，Miku独唱14→11、参与合唱2→4、不含Miku8→10；独唱份额下降14.3个百分点。这支持“个人曲目份额减少”，不能未经录像计时就写成演唱时间减少14.3%。

**已观察：其他五人的参与曲数在部分年份完全相等。**

### 同一首歌与收尾位置，也值得观察

- **《Hand in Hand》：** 2020列有此曲的配置以及2021—2023官方表署名Miku；2024—2026署名六人。相同曲名的演出署名确实改变，但不能只据署名推算每人演唱分钟。
- **收尾：** 2025最后一首《ラストラス》署名Miku；2026最后两首《Hand in Hand》《こたえて》均署名六人。共同收尾可能影响“整场属于谁”的观感，这是解释假设；本文未完成MC、镜头、服装及声部的录像审计。
- **反例：** 2023《Birthday Song for ミク》署名其他五人，统计为不含Miku，但歌曲主题围绕她。表演者份额与被庆祝对象的中心意义不相同，不能把这首曲目简单解释为去中心化。

### 情感四项怎样取值？

|项目|观察内容|
|---|---|
|情感表达|一歌怎样表达对这个人的珍惜、喜欢、感激或依恋|
|信任与袒露|是否愿意向对方说明自己的脆弱、不安和内心冲突|
|主动投入|是否主动分享、关心、回礼或回应对方的愿望|
|关系定位|是否明确赋予对方持续的个人意义|

每项0～4：0为已核查范围内未找到证据，1为一般友好或感谢，2为明确的个人情感证据，3为深层感受或跨情境持续表现，4为既深层又持续的稳定关系特征。未评估留空，不能填0。感谢次数、同场次数、技能求助次数都不能直接累加升档。

```text
情感指数 = 100 × (情感表达 + 信任与袒露 + 主动投入 + 关系定位) / 16
```

这是待继续检验的文本评分方案，不是角色内心感情的客观测量。V3 的 S 已涉及自我归因与关系锚定，因此不把成长与情感直接相加，避免在一个总分里重复奖励同一段台词。

本轮使用 [ci-ke/ProjectSekai-story 的固定日文文本快照](https://github.com/ci-ke/ProjectSekai-story/tree/fdfbd5de4f28f21a326d031439feb9b0491111a5/story_jp)，属于第三方游戏剧情整理，并非官方发布库。报告链接固定到原文行；尚未逐句对照游戏画面。声优、社区观点和中文译文未参与此次评分。

## 怎样判断一段关系的重要性？

先看剧情中发生了什么，再谈分数。每条判断都应说明：

1. 角色当时面临什么问题？
2. 虚拟歌手具体说了什么、做了什么？
3. 角色随后发生了什么变化？
4. 后面的剧情是否再次提到这次帮助？

还要保留角色本人、伙伴和其他人物的贡献。例如，角色在某位虚拟歌手登场前已经作出了决定，就不能把那位虚拟歌手之后的鼓励写成这次决定的原因。几个人同时在场，也不表示他们起了同样的作用。

判断优先依据主线、活动和卡牌剧情正文，再参考区域对话、官方回顾或人物介绍。羁绊称号、活动加成、卡池、演唱安排和社区观点可以提供查找线索，但不能单独证明重要的成长影响。媒体回顾也需要与正文核对。

### 一个核查例子

在《聖なる夜に、この歌声を》中，宁宁先通过童年录像重新理解表演的快乐，并恢复练习，MEIKO 随后才登场。MEIKO 提供了演出的支持，但这段剧情不能证明“是她让宁宁恢复了练习的勇气”。查看[第6话](https://pjsk.moe/ja-jp/story/event/8/6/)和[第7话](https://pjsk.moe/ja-jp/story/event/8/7/)。

这类核查不会否定两人的其他关系，只会修正这条具体解释。

## V3 看哪五个方面？

|方面|用容易理解的话说|记录符号|
|---|---|---|
|影响有多深|是一次具体帮助，还是影响了角色的重要选择、自我认识或人生道路？|K|
|有几条独立的成长经历|除了这一次，是否还在别的成长问题上起过重要作用？|C|
|角色自己怎么说|角色有没有明确说“因为你，我才改变”，或直接说明对方对自己的特殊意义？|S|
|影响持续多久|作用只发生在一个阶段，还是在相隔较远的时期持续出现？|T|
|帮助涉及哪些方面|只涉及一种问题，还是也涉及创作、职业、伙伴关系等不同方面？|B|

这五项合起来记作 **(K,C,S,T,B)**。字母只是记录用的简写，具体依据始终是剧情。

### 1. 影响有多深：K

|等级|意思|
|---|---|
|K0|在已经检查的范围内，没有找到有效关系证据|
|K1|提供了具体帮助|
|K2|改变了角色的行动或决定|
|K3|影响了角色的核心困惑、自我认识、重要关系或创作方向|
|K4|进入了角色的人生起点、核心身份或长期道路|

取证据支持的最高一档。许多次普通帮助，不会自动累加成一次人生转折。**没有检查过的关系应写“待查”，不能直接记为 K0。**

### 2. 有几条独立的成长经历：C

只统计达到 K2 或以上的独立剧情线，也就是确实改变过角色行动或决定的经历。

|独立剧情线数量|C 的取值|
|---|---:|
|0条|0|
|1条|4|
|2条|7|
|3条|9|
|4条及以上|10|

第一条最重要，之后每新增一条，增加的分数逐渐减少；4条后不再加分，但新证据仍然保留。

同一段谈话跨了几章，或角色后来再次想起同一句建议，通常仍属于同一条成长线。只有出现独立的成长问题、帮助过程和变化，才另算一条。**剧情线的条数与 C 的取值不同：例如2条对应 C=7。**

### 3. 角色自己怎么说：S

|取值|正文中的表达|
|---|---|
|0|没有明确表达|
|1|明确表达感谢、信任或依赖|
|2|明确说某次改变是因为这位虚拟歌手|
|3|明确把重大成长或人生结果归功于对方|
|4|明确给予特殊关系定位，例如“最重要的前辈和朋友”|

记录正文支持的最高一档，不按感谢次数累加。这项反映角色自己的说法，不衡量感情深浅，也不能代替对实际因果的检查。

### 4. 影响持续多久：T

|取值|持续情况|
|---|---|
|0|只见于单一时期|
|1|跨两个时期|
|2|跨三个时期|
|3|长期跨年持续|

评价时需要说明如何划分时期，并列出相应剧情的日期或阶段。比较同一角色的不同关系时，要使用一致的划分。同一活动的连续三章不能算三个时期，作品连载了很多年也不代表每段关系都持续发挥作用。

### 5. 帮助涉及哪些方面：B

按有证据支持的帮助类型计数：0类记0，1类记1，2类记2，3类记3，4类及以上记4。

例如创作、职业选择、自我认识、伙伴关系可以是不同方面；只是换一种说法描述同一次帮助，不能多算。帮助范围只占很小的比重，不能替代影响深度。

## 怎样比较，分数又有什么用？

比较时，**先看影响深度 K**。K 相同，再依次比较角色自己的说法 S、独立成长经历 C、持续时间 T、帮助范围 B；五项完全相同就并列。

因此，一段 K4 关系即使展示分数稍低，也排在 K3 关系之前。不能只把所有分数从高到低排列，就当作研究结论。

为了方便画表和检查不同判断带来的变化，五项也可以换算成0–100的展示指数 I。它不是“感情值”，100只表示五项都达到这套规则的上限，第一名不一定是100。

<details>
<summary>展开查看公式、权重和计算例子</summary>

将每项除以各自的上限，再按以下比重相加：影响深度50%，角色自己的说法20%，独立成长经历15%，持续时间10%，帮助范围5%。

```text
K_norm = K / 4
S_norm = S / 4
C_norm = C / 10
T_norm = T / 3
B_norm = B / 4

I = 50*K_norm + 20*S_norm + 15*C_norm + 10*T_norm + 5*B_norm
```

例如，2条独立成长线对应 C=7，记录为 (3,7,2,2,2) 时，展示指数约为67.17。另一段关系是 (4,4,0,0,1)，展示指数为57.25，但因 K 更高，仍排在前面。这两个例子只演示计算，不代表具体角色的评价。

记录顺序是 **(K,C,S,T,B)**，比较顺序是 **K → S → C → T → B**。显示时可以四舍五入，比较时使用原始五项记录。

V3 不再使用逐事件乘倍率后累加、2.2次幂，或把每名角色的最高分强行拉到100的做法。另一位虚拟歌手也有类似贡献，不会让已经证实的帮助被扣分。

如果某项尚未查清，就写“待定”，不以0补齐计算。需要检查结论是否稳妥时，应重新查看影响等级、剧情线是否重复、角色台词和时期划分；调整展示权重不能绕过前面的比较顺序。

</details>

## 我们对结论有多大把握？

**重要程度与证据充分程度是两回事。** 一段剧情可以清楚证明某次帮助发生过，但要判断“这位虚拟歌手长期最重要”，还需要检查后续剧情和其他虚拟歌手的贡献。

置信度沿用 **A+ / A / A− / B+ / B / C / F**。它不加进分数，不作为倍率，也不参与五项的比较顺序；这些字母不是统计概率。

|置信度|怎样理解|
|---|---|
|A+|多条重要剧情跨时期相互印证，其他主要候选也已充分检查，结论几乎没有合理争议|
|A|有直接涉及角色核心问题的重要事件，并在后续持续得到支持；检查其他主要候选后，领先仍较稳定|
|A−|领先者证据很强，但另一位也有独立、重要的成长贡献，需要解释为什么仍这样判断|
|B+|目前有直接证据支持领先者，但也发现了足以挑战它的证据，尚不能确认稳定领先|
|B|资料覆盖不足，或换一种合理的等级判断、剧情线划分，就可能改变结论|
|C|主要依据概要、媒体回顾等间接资料，关键行动、顺序和因果还没有回到正文核对|
|F|论据没有通过最低证据要求，例如只凭配对想象、颜色相近或未经剧情支持的个人解释|

F 评价的是这条论据，不是创作者或读者，也不表示这对角色没有关系。错误论据应撤销；其他已经核实的证据继续保留。
