# PJSK中虚拟歌手和原创角色的关系研究

这个关系研究的主旨可以概括成一句话：

不讨论“谁最配谁”，而是研究6名Virtual Singer分别在20名原创角色的人物成长中承担了什么功能，以及这种关系是单核心、双核心还是多核心结构。

具体来说，我们主要看三件事：某个V是否进入过OC的核心剧情矛盾，是否真正改变过角色的决定或成长方向，以及这种作用是否长期、独特、可重复验证。最终不是只给“第一名”，而是画出每个OC的关系拓扑。

所以“芯片塑”只是一个很直观的表达方式：

S-core = 一个V明显主导人物核心线；
多P-core = 多个V分别承担不同的重要成长线程；
E-core = 关系相对不明显的虚拟歌手
CPU0 = 从角色/SEKAI初始化阶段就具有不可替代基础地位的V；
Affinity = 不同V最擅长处理哪类剧情问题。

本质上，这是一个把PJSK的 OC–VS关系从主观印象，转成可查剧情、可复算、可由其他AI挑战的结构化分析。

PJSK OC–Virtual Singer 关系评测：v2.3 定向审计复跑

完成日期：2026-09-19。本文沿用用户的CPU/SoC隐喻：CPU0是初始化与基础结构地位，S/P/E表示叙事重要性和强度；不解释成CP、好感度或同框频率。

**结论：原版的大方向有多项能成立，但120个具体分数没有被验证；宁宁的关键S级依据存在明确的因果顺序错误，彰人的主线贡献分配也需要重写。冬弥、奏、司、类应重新开放竞争。真冬—Miku的CPU0判断可以与排名分开保留。**

本轮建立118条OC–VS记账项（117条正分、1条零分对照），引用108话，涉及46个活动及4条组合主线。多条账目可能来自同一场景，因此118不表示118个互不相关的剧情事件。核查方式为关键章通读与相关对白、前后因果段落核查相结合。

这是针对给定基线和竞争证据的抽样复跑，不是截至2026年的全剧情普查。计分活动最晚到2024年的活动150；卡牌与区域对话未系统覆盖。下面的Raw是**已核查事件在指定编码下的Raw**，不是角色全部剧情的真实总量。等级、主动性和影响倍率仍是分析判断，不能因为数学可复算就叫客观测量。

完整逐项账本见 [PJSK_ledger.md](PJSK_ledger.md)，机器账本见 [PJSK_event_ledger.json](PJSK_event_ledger.json)，计算结果见 [PJSK_scores.json](PJSK_scores.json)。

## 原始评分标准：分数如何产生、应该怎样读

本节依据仓库内的 [v2.2-Audit 原始 handoff](PJSK_v2.2_handoff.txt) 解释原本的评判方法。**原规范是评分框架，原来的20×6矩阵是待核验的基线；两者不能混同。** 原表并没有完整事件账本，因此不能声称其中每个数字都已经按下列公式算出。后文的 v2.3 数字来自本轮已核查的抽样账本。


### 1. 评分对象和证据门槛

每次评分固定一名原创角色（OC），比较六名虚拟歌手（VS）在其人物成长中承担的作用：是否触及核心矛盾、促成重要决定，以及是否持续参与创作、职业、搭档、自我认同等人物线。得分描述剧情中的重要性与强度，不衡量恋爱关系、好感度或角色人气。

原规范的证据优先级依次为：主线正文 → 活动正文 → 卡牌支线正文 → 区域对话 → 官方剧情回顾或官方/合作媒体角色介绍 → 羁绊称号 → 活动 Bonus、卡池与演唱配置 → 社区观点。最后三类只能辅助定位和理解，不能单独产生高分。同框多、性格相似、同池或同歌，也不能直接换算成强关系。媒体文章是否属于官方资料仍需核实，原 handoff 对 Famitsu 的称呼问题见后文来源说明。

每条有效账目应记录 OC、VS、剧情名称、章节、事件摘要、主题、等级、各倍率、重复权重和事件分。关键是说明“该 VS 做了什么、OC 因此发生了什么变化”，并保留 OC 自己及其他人物的作用。只有角色定位或导师身份，没有对应行动与影响，不能自动算成重大事件。

### 2. 单个事件的基础分

|事件等级|原始判定标准|基础分 Base|
|---|---|---:|
|S|直接触及底层人格、创伤、人生目标、音乐根源或自我认同，并影响后续长期人物线|16|
|A|主导重要主线或角色焦点活动的转折，促成明确的重要决定或认知变化|8|
|B|实质性一对一帮助，影响当前事件或行为|3|
|C|明确的日常陪伴、鼓励、咨询或关系互动|1|
|D|仅同场、同池、同歌或同 Bonus，没有可说明的有效作用|0|

这套权重让一次人物根本问题上的干预，比普通帮助和日常互动更重。S 的16分是 A 的两倍，但分级本身仍需要解释剧情因果，不能只凭场面感人或台词强烈决定。这里的“事件 A 级”与下一项“主动性倍率 A”只是字母相同，含义不同。

### 3. 三类倍率：主动性 A、后续影响 I、关系独占性 U

|倍率|对应情况|取值|
|---|---|---:|
|A：主动性|OC 主动寻找该 VS 求助、倾诉或咨询|1.25|
|A：主动性|OC 主动深入回应|1.10|
|A：主动性|VS 主动介入|1.00|
|A：主动性|偶然产生互动|0.85|
|I：后续影响|改变长期人物路线、价值观或核心决定|1.35|
|I：后续影响|改变该活动的重要决定|1.20|
|I：后续影响|有明确帮助|1.00|
|I：后续影响|主要为情绪安慰|0.90|
|U：关系独占性|该主题长期几乎只有此 VS 承担|1.40|
|U：关系独占性|明显独特，但其他 VS 偶有介入|1.20|
|U：关系独占性|多个 VS 共同承担|1.00|
|U：关系独占性|泛用鼓励|0.80|

每个维度按事件证据选一个值，不把同一维度的多档相加或连乘。A 考察 OC 如何参与，I 考察产生了多大后续影响，U 考察这一主题是否主要由该 VS 承担。U 的高值需要对其他 VS 有足够覆盖，不能把“目前只查到这一位”当作“长期只有这一位”。这些倍率是原模型的人为权重，不是剧情给出的客观量尺。

### 4. 主题与重复衰减

事件按 **OC–VS–Affinity（主题）** 分组，同组事件按重要性排序后赋予重复权重：

|同组排序|Repeat|
|---|---:|
|第1条|1.00|
|第2条|0.60|
|第3条|0.35|
|第4条及以后|0.20|

主题包括自我认同、音乐初心、创作、职业道路、舞台、自信、创伤、搭档、团队、人际关系、情绪识别、冲突处理、生活经验、梦想、秘密/距离、自我表达、领导/管理、专业技能及其他。它们用于区分作用不同的剧情线程；同一对 OC–VS 可以拥有多个主题。

原规则允许完全不同的主题分别起算；不同 VS 本来就在不同分组中，不互相衰减。同一行动不能仅靠贴上多个标签重复入账。原规范只写“按重要性排序”；v2.3 将其具体化为先按等级、再按衰减前事件分排序，完全相同则用账目 ID 确定顺序。

重复衰减的目的在于降低相似日常事件堆积的优势，但第4条以后恒为20%，仍可随条数无限累积。因此它能减缓累积，不能严格保证“无限刷分”不发生。

### 5. 从事件分到 Raw、最终展示分

完整计算链为：

```text
单事件有效分 Event Raw = Base × A × I × U × Repeat
某 OC–VS 的 Raw = 该对关系全部有效事件分之和
MaxRaw = 同一 OC 的六名 VS 中最高的 Raw
Final = 100 × (Raw / MaxRaw)^2.2
```

原规范前半部分将衰减前的 `Base × A × I × U` 记为 E，后半部分把 Repeat 也写入事件公式；这里统一展示完整公式，重复权重只乘一次。

**演算示例（仅说明算法，不新增剧情证据）：** 假设一条 S 级事件中，OC 主动深入回应、产生长期影响、由多个 VS 共同承担该主题，且是同组第一条，则有效分为 `16 × 1.10 × 1.35 × 1.00 × 1.00 = 23.76`。若同组还有一条 B 级明确帮助，A=1.10、I=1.00、U=1.00，排第二条，则计 `3 × 1.10 × 1.00 × 1.00 × 0.60 = 1.98`。两条合计 Raw=25.74；它在六名 VS 中是否第一，还需要比较其余五位的账本。

只有 MaxRaw>0 时，归一化才有意义；并列第一可以同时为100。**100表示这名 OC 内部最高，不是绝对满分，也不表示不同 OC 的两个100具有同等剧情深度。** 2.2次幂保持名次，同时放大差距：Raw 比例为100/80/60/40时，展示分约为100/61/33/13；Raw 比例为100/95/90时，约为100/89/79。因此图表上的“断崖”既受证据影响，也受指数选择影响。

### 6. 差异性 D 与 S/P/E 核心分类

将同一 OC 的六个 Final 从高到低排列为 S₁…S₆，其中 S₁=100：

```text
D = 100 − (S₂ + S₃ + S₄ + S₅ + S₆) / 5
```

这里的 S₁…S₆ 只是分数序号，不是 S 级事件。并列最高时只排除一个100，其余100仍进入五项平均。D 越高，表示该分布越集中于一个最高项；D 越低，表示其他 VS 的相对得分总体越高。例如100/80/20/20/20/20的 D=68，但仍有明显第二强核，不能仅凭 D 判断为单核。

CPU/SoC 术语在这里是叙事功能的比喻，S/P/E 表达重要性与强度。原规范提供以下分布示意，并非完整、互斥的分类算法：

|原分类|原设定的典型形状或条件|如何理解|
|---|---|---|
|S-core 型|100 / <55 / …|一个关系明显突出|
|1S + 1P|100 / 70–90 / 后续明显下降|第一核之外还有一个强第二核|
|2P / 多P|至少两到三名 VS 达到约70以上，并有独立重大剧情线程|多个 VS 在不同方面承担重要作用|
|x86 多大核|100 / 90 / 80 / 70 / …|多个 VS 都能参与核心人物剧情，主题与优先作用有所不同|
|E-core|原文没有给出独立的数值阈值|可在术语层面理解为较轻的日常或辅助作用；不能据此给任意低分项自动定级|

原分类对第二项55–70、约90附近的边界及分类重叠没有完整规定。v2.3 因此采用“过渡形”“高竞争双峰”等描述，并把它们限定为样本形状。**事件 S 级、关系 S-core 和 Final=100 是不同概念：一条 B 级事件也可能因样本缺少其他证据而归一到100，不能因此升级为 S 级或确定全局 S-core。**

### 7. CPU0 单独判断

CPU0 表示初始化与基础结构地位，需综合考虑：早期主线已存在、与 OC/SEKAI 的初始化高度相关、长期常驻，以及其基础作用是否不因后来某次更强烈的干预而被取代。它不从 Final 或 D 自动推出，也没有额外加分公式。

原规范以真冬—Miku为例：Miku的基础地位，与KAITO可能在某些具体人物转折中发挥更强作用，可以同时成立。CPU0判断与“谁的累计Raw最高”必须分开检验。

### 8. 置信度是证据评价，不是额外分数
### 8. 置信度是证据评价，不是额外分数

置信度回答的是：**现有证据有多充分，足不足以支持这项关系判断或第一名排序？** 它不参与 Raw 的乘法，也不是统计概率。

必须区分“某个剧情事件确实发生”和“该 VS 是这个 OC 的稳定第一核”。前者可以由具体章节证实；后者还需要长期复现、竞争者比较和足够的剧情覆盖。

下表用剧情案例解释判据。**案例用于说明如何判断，不代表本轮已经给对应关系授予该档置信度；本轮全局排名仍因覆盖不足暂列 B。**

| 置信度 | 判定标准 | 游戏剧情例子与解释 |
|---|---|---|
| **A+** | 多个主线或角色焦点活动的硬事件相互印证，跨时期持续成立，充分核查竞争者后仍几乎没有合理争议。 | **一歌—Miku是可以据此继续检验的候选。**《つなぐ、星の歌》第4话中，一歌回顾自己因Miku想组乐队、伙伴借SEKAI重新连接，以及通过Miku的音乐与奏建立联系。这种由OC本人明确说明其人生影响的剧情，是强证据。但要给“稳定第一”A+，仍须核查这些作用在其他剧情中的复现及其余VS的贡献，不能凭这一话直接定档。 |
| **A** | 至少一个S级事件，加上长期复现；核查主要竞争者后，第一名仍较稳定。 | **绘名—Rin可用于理解“核心事件＋后续复现”。**《満たされないペイルカラー》触及绘名对外界认可与绘画价值的根本困惑；本轮账本又记录了后续World Link及父亲画展相关剧情中的支持。前后呼应比一次安慰更有说服力。若进一步核查其他VS后仍保持稳定领先，才符合A。 |
| **A−** | 第一名有较强硬证据，但第二核也承担重要、独立的核心剧情，领先需要具体解释。 | **真冬—Miku与KAITO的比较可以说明这种情况。**Miku具有早期主线和长期陪伴的基础作用；KAITO则有推动真冬自我保护的实质干预。若充分核查后仍判断Miku第一，也必须解释为何其累计作用更重要，不能仅凭CPU0身份排除KAITO的竞争。CPU0本身不自动提高排名置信度。 |
| **B+** | 当前第一有直接剧情依据，但已发现足以挑战它的竞争证据，尚不能确认稳定领先。 | **杏—Miku与Len是直观例子。**《Bout for Beside You》第5—6话中，Len的话触发杏对搭档关系的不安，Miku进一步陪她辨认并说出这种恐惧。双方都有可辨认的因果贡献。如果暂把Miku排第一，仍须说明为何后续引导重于最初触发；这段剧情本身不能证明原表的100∶92。 |
| **B** | 数据覆盖不足，或第一名对事件分级、倍率、主题划分等设定高度敏感。 | **冬弥—KAITO/Luka是本轮的实际例子。**《Walk on and on》第6—7话中，KAITO帮助冬弥重新认识古典训练的价值。本轮将这项作用评为S时，样本KAITO领先；只把该事件降为A，Luka就会反超。这说明第一名依赖一个可争论的分级，不能称为稳定结论。 |
| **C** | 当前主要依赖剧情概要、媒体回顾等间接资料，尚未用正文核对关键行动、时序与因果。 | **原版宁宁—MEIKO的“治愈舞台创伤”论据说明为什么需要这一档。**只读回顾，容易把MEIKO参与演出理解为宁宁恢复勇气的原因；核对《聖なる夜に、この歌声を》第6—7话后，却发现宁宁先恢复练习，MEIKO随后才登场。正文未核查时，这类判断只能暂列C；核查发现因果错误后，应撤销该具体论据，不能继续以“低置信度”保留它的高分。 |
| **F** | 仅有同人偏好、配对想象、外观联想或未经剧情支持的个人解释，没有可核验的有效剧情依据。 | **例如：“某同人爱好者觉得星乃一歌和KAITO都是蓝色系，还有师生关系，所以很配。”**颜色相近和“很配”的感受不能证明人物成长中的结构性作用；即使某种指导关系能被正文证实，也必须具体说明教了什么、造成什么改变。这段配对解释本身评为F，**对本研究判断的影响为0，不产生事件分，也不能支持排名。** |

**F评价的是论据，不是同人爱好者的身份。** 同人作者如果提供了准确的剧情章节和可核验的因果分析，应按原始证据重新评价；官方或媒体资料如果不能支持所声称的因果，也不能仅凭来源身份获得高置信度。

这里的“F影响为0”表示该解释不进入有效证据和计分依据，**不是断言这对角色的真实关系为零**，也不是把已经核实的其他事件一并清零。

置信度不参与 Raw 的乘法，也不是统计概率。原表中的“Miku A+”等写法，是排名及其证据置信度，不是又一种事件等级。竞争者剧情没有系统核查时，即使某条事件事实明确，也不足以给全局第一很高置信度。

### 9. 本轮 v2.3 怎样使用这些规则

本轮保留原基础分、A/I候选值、重复权重、2.2次幂和D公式，但将 **U统一设为1.00**，作为覆盖不足时的中性审计设定；既不授予独占奖励，也不使用0.80的泛用折扣。这不是断言所有关系都同样独特。连续谈话和后来的同一建议回想不重复制造重大事件，具体记账和敏感性检查见后文。

本轮全局排名置信度统一暂列B，未覆盖的关系不被判定为真实零作用。表格用“—”标识没有正分观察的项；为计算样本Final和D，程序暂按样本Raw=0处理，所以这些结果只能描述已记录的样本。补证据时，应修改或增加事件账目并重新计算，而不能直接把目标Final写进表格。

**评分约定与必须修正的模型问题**

- 本轮保留S=16、A=8、B=3、C=1及原A/I候选值。U统一设1.00作为中性审计设定：覆盖不足时不授独占奖励。它不是关于所有关系均等独特的事实判断，也未套用泛用互动0.80折扣。未来可修改JSON逐项U再重算。

- 同一连续谈话跨章合并；后来回想同一段建议只作为影响证据，不再新建重事件。相同OC–VS–主题按等级、衰减前Raw排序，再用1、0.6、0.35、0.2。零分对照不占重复序号。

- 同一行动不能通过换标签加分；另行完成的教学、分享作品等行动可单列。主题边界仍会影响结果，因此提供把同一OC–VS所有主题合并衰减的压力测试。该测试比原规则更严，不是默认替换。

- 不要求参与一场戏的VS共同分掉一个固定分池；各自要有独立的可说明贡献，U=1记录共享功能。OC、伙伴及NPC的贡献另在摘要中保留，不能被VS吞掉。

- 第4次以后恒定20%仍然可以无限累积：再加n个同权事件仍增加0.2nE。它只能减缓刷分，不能数学上防止无限刷分。建议下一版明确采用尾部几何衰减或每主题上限；本轮为可比性没有暗改。

- 2.2次幂不改变同一OC内部的名次，却显著改变断崖与Core Type。Raw相对第一为80%时，显示分只有61.2；显示70对应Raw约85.0%。因此Core阈值属于模型选择，不是剧情事实。

- 原表真冬100∶95隐含第二名Raw约为第一名97.7%，仅差约2.3%。这不影响CPU0结构判断，却与“几乎无合理竞争者”的排名A+标准紧张。原表20个D的算术均正确；错误风险主要在事件、分级、覆盖与倍率，而非减法。
