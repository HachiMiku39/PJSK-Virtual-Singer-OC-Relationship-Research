# PJSK是否“端水”：分配结果、制作职责与因果边界

更新：2026-10-12。这是公开材料与剧情编码的研究分析，不是内部决策记录。

[返回首页](../../README.md) · [120组逐维研究](../all-characters/README.md) · [交互图表](../all-characters/dashboard.html) · [魔法未来2020—2026逐曲原记录](../miku-centrality/mirai-setlists.json) · [原专题与详细计数口径](../miku-centrality/README.md)

**可以观察到照顾多位VS、共享内容，以及魔法未来部分年份非Miku五人的参与曲数均衡。但没有公开证据足以断言六人的剧情重要性被强行拉平，或证明PJSK造成了魔法未来的配置变化，更无法确认某个人或某家公司下达了“削弱Miku/强制均分”的指令。**

## “端水”具体指什么？

|可检验含义|本轮判断|证据与限制|
|---|---|---|
|让六位VS都拥有可识别的互动或帮助|存在群像照顾的文本表现|全角色核验记录中有不同VS的具体作用；生日共同筹备、跨SEKAI交往也存在。不能据此推导“每位必须同等分量”的配额。|
|让角色对六位VS的关系同质、同强|当前材料不支持笼统断言|20个角色没有一组六位VS成长向量完全相同。生日礼物与群体感谢不会自动给六位相同强线。这个编码结果不是官方意图的独立测量。|
|为了轮流分戏而牺牲逻辑、淡化既有特殊关系|证据不足|需要可对照的前后剧情、具体不合理接管行动和长期内容趋势；同分或共同出场本身不够。|
|演唱会给非Miku五位相近参与曲数|部分年份确实存在|2023各4、2025各6、2026各5；Miku分别12、15、17，仍非六人平分。详见官方表与逐曲记录。|
|PJSK促成了这些演唱会变化|未建立因果链|六位共同登台在游戏上线前已有；没有可归属的公开调整指令或对照研究。|

这里没有把成长与情感指数、卡牌数、服装、曲数、声部分钟和品牌定位合成一个“待遇分”。它们属于不同分配对象。

## 120组关系能说明什么？

本轮114组与一歌6组保留首評覆盖20×6。后续针对4组补读24个窗口，原5项情感待查都有具名正文支持，当前两套120组原始指数完整；此后46个初始同分组合逐组比较，修订2组投入分档并复查新/变化组合，50份记录覆盖最终47个同分组合，保留并列都有理由，见[同分深入评价](../all-characters/tie-review.md)。分档仍是研究判断。核验完成是每组作出证据判断，不是全4147篇逐行穷尽，也不是官方打分。完整解释与来源见[全角色报告](../all-characters/README.md)。

不同组的因果与感情方向并不统一：

- 一歌—Miku保留现实歌声带来的起点、持续创作与显式关系意义；成长、情感均到原量尺上限。其他五位有真实关系，不意味着她们取得同样的根基地位。
- 心羽—铃/连的K4包括杏演唱铃/连作品所带来的起点，**由杏及作品媒介承接**，不能改写成SEKAI歌手在童年亲自教她；相应情感分也没有随K4自动到顶。
- 真冬—Miku的K4包含本人关于若没有奏与Miku相遇可能消失的共同、假设性归因，及保存真实思绪的愿望；不独占奏的作用，不代表她已完全恢复。这个新的全角色结论不把旧报告“在一歌六组中Miku唯一K4”误扩成全20角色唯一K4。
- 瑞希—MEIKO/Luka的重要作用与瑞希对连的明确温柔定位并存；Rin的投入证据来自瑞希为她选礼物，不因此倒算成Rin帮助瑞希的核心成长。补查035-03后，Rin的信任取2：瑞希直接说自己察觉他人隐藏想法、导致人际关系失败，但仍回避是否痛苦的追问，不夸成完整秘密告白。
- 绘名对Miku与KAITO共同道谢，184话中实际给创作课题关键追问的是KAITO，完整理论教育来自雪平；不能因共同被感谢，把同一份个别指导平均发给两位。

这些案例更符合“多种关系受到描写，但性质不同”。本次人工编码也有偏差可能：K、功能分类和情感2/3档仍有判断空间，候选检索对稀有转折不一定召回。不能把研究者做出的差异图反过来当作官方绝无配额的证据。

显示指数会压缩视觉差距：K4与K3在成长I中相差12.5，C在4条强线后封顶，情感3档可由跨情境个人关心支撑。因而雷达轮廓相近不自动证明编剧端水；也不能为了扩大Miku领先而事后加权。

## 补查到的明确策划表述：有平衡意识，作用范围有限

Colorful Palette的2021周年活动幕后报告明确说，3DMV上映会原本不在最初方案中，是活动企划者为增加粉丝喜欢的内容提出的；安排上映时关注组合间平衡与歌曲顺序。这是公开可归属到CP活动策划流程的**局部平衡目标**，比只观察相等曲数更接近制作意图。但它谈的是2021周年活动的组合与上映编排，不是六位VS的剧情功劳、魔法未来的配额或削弱Miku的指令。[CP官方2021幕后报告](https://media.colorfulpalette.co.jp/n/n1560a9b4c579)

2024 VS首轮World Link卡面制作访谈则说明，团队希望同时表现六人的特征，并给Miku/Luka、Rin/Len、KAITO/MEIKO三对共同主题。它支持有意识地描写六人群像与不同个性；卡面主题配对不能证明编剧给六人相同重要性。[CP官方2024卡面访谈](https://media.colorfulpalette.co.jp/n/nd64f7662d5f3)

PJSK官方人物页区分现实世界的歌手与SEKAI中的不同形象，公开将后者描述为协助角色发现真实心意、一起歌唱。共同的支持定位是世界观机制，尚未公开同等戏份/成长因果配额。[官方VS介绍](https://pjsekai.sega.jp/character/virtualsinger/index.html)

因此，能进一步确认的是：**CP在特定活动的编排上有公开的平衡意识，六人群像的设计也有公开制作意图。** 再推成整个PJSK的六VS统一均分政策、CFM/SEGA指使或影响魔法未来，仍需另有明确证据。

## 相对100分对“端水”观察的影响

按本轮用户指定，展示新增“每角色、每指标最高原始值为100”的相对分。原始K/C/S/T/B、四情感档与指数全部保留。每个角色出现至少一位100是计算规则的必然结果，**不是官方把角色关系拉到相同深度的证据**。判断全体分配和跨角色绝对差异，应回看原始分档及正文；不能拿归一后的雷达面积直接证明端水。

## 几种竞争解释与尚缺的材料

|假设|能解释的观察|本轮不足与可证伪条件|
|---|---|---|
|照顾不同VS受众、拓展群像关系|多人周年内容、个人喜好回礼、不同指导关系|合理商业/创作解释，不是已确认动机；需公开方针或策划访谈|
|周年、年度主题与曲库导致临时均衡|2019流歌主题、年度曲目配置有波动|需要跨年控制主题/周年、制作与选曲资料；相同配额年不一定同一原因|
|存在五人参与曲数的策划目标|2023/2025/2026五人曲数完全相等|可观察配置支持，尚无内部说明；次数不测声部/时长|
|PJSK成功推动CFM跨项目群像化|上线后某些均衡配置与共享曲署名出现|缺游戏上线前多年同口径基线、明确决策时间链；2019既有六人参与削弱“首次引入”版本|
|主动削弱Miku或强迫所有关系同质|部分年度个人独唱份额较低|2024/2026回升及持续中心品牌、关系差异是反证/限制；需长期绝对内容与特殊定位前后比较|

截至补查，已找到CP特定上映活动关注组合平衡的公开说明，但没有找到足以确认“六VS剧情/舞台一律均分”或“削弱Miku”的公开配额文件或内部指令。没有找到不等于不存在；研究将它标为未证明，而不以粉丝愤怒、公司名单或相关性替代证据。
